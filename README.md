# Elixir Livebook Koans

Elixir Livebook Koans is a fun way to get started with the elixir programming language. It is a tour of the most important features and idiomatic usage of the language.

## Prerequisites

Must have installed [Livebook](https://livebook.dev/)

## How to Use

Open [koans.livemd](koans.livemd) and select the koan you want
to practice.
